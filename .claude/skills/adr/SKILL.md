# Architecture Decision Record

1. List `docs/adr/` and take the next free four-digit number.
2. Copy `0000-template.md` to `NNNN-kebab-case-title.md`.
3. Fill in Context, Decision, Alternatives considered, Consequences. Status starts as
   `Proposed`; only the user moves it to `Accepted`.
4. If it supersedes an ADR, set the old one's status to `Superseded by NNNN`.
5. Add the ADR to the index table in `docs/adr/README.md`.
